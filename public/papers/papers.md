# Publications catalog

Machine-readable catalog of the PDFs in `public/papers/`. File naming convention: `year_firstauthorlastname_shorttitle.pdf` (lowercase, ASCII, underscores). One entry per PDF; each entry has a one-sentence summary and keywords intended to drive project/topic pages on the research-hub website. Suggested project groupings are at the end.

Entries are ordered newest → oldest. Summaries were written from the title and abstract of each PDF.
