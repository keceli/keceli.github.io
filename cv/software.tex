\resheading{Software Products} 
\begin{itemize}
    \resitem{ChemGraph (Project lead) is an agentic framework for computational chemistry and material science. Available on \href{https://github.com/argonne-lcf/ChemGraph}{GitHub}.}
    \resitem{Interactive Quantum Chemistry (IQC, lead developer) automates high-throughput workflows and provides an interactive dashboard for computational chemistry and material science. Available on \href{https://github.com/Autonomous-Scientific-Agents/IQC}{GitHub}.}
    \resitem{Quantum Thermochemistry Calculator (QTC, lead developer) automates workflows for accurate thermochemsitry calculations. Available on \href{https://github.com/keceli/QTC}{GitHub}.}
   % \resitem{ MPI-Benchmark, developer. A repo for singularity container rec https://github.com/keceli/mpi_benchmark}
    \resitem{VALENCE (co-developer) is a quantum chemistry code that provides a massively parallel implementation of variational subspace valence bond method. Available on \href{https://github.com/VALENCE-software/VALENCE}{GitHub}.}
    \resitem{Auto-Mech (co-developer) is a software suite that automates high-accuracy quantum chemistry, thermochemistry, and kinetics calculations. Available on \href{https://github.com/Auto-Mech}{GitHub}.}
    \resitem{NWChemEx (co-developer) is an electronic structure package focusing on high-performance computing and reduced scaling methodologies. Available on \href{https://github.com/NWChemEx}{GitHub}. Some of the repos will be released within this year.}
    \resitem{ezHPC (developer) is a set of Jupyter notebooks that provides interactive features for ALCF supercomputers. Avaiable on \href{https://github.com/keceli/ezHPC}{GitHub}.}
    \resitem{miniGAP (co-developer) is a proxy application for molecular and materials property prediction using the Gaussian Process Approximation. Available on \href{https://github.com/alvarovm/minigap}{GitHub}.}
    \resitem{NinjaParser (developer) is a Python script to parse ninja log files to identify codes with longest compilation times. Available on \href{https://github.com/keceli/NinjaParser}{GitHub}.}
    \resitem{Contributed to various other open-source projects, such as \href{https://github.com/ValeevGroup/tiledarray}{TiledArray}, \href{https://github.com/m-a-d-n-e-s-s/madness}{MADNESS}, \href{https://github.com/google/ffn}{Google/FFN}, and \href{https://github.com/argonne-lcf/balsam}{Balsam}.}
